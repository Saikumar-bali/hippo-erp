# AI Run Reports

Each implementation run should add one markdown report in this folder.

Use this filename pattern:

```text
YYYY-MM-DD_phase-X-Y_short-title.md
```

Each report should include:

- goal
- branch name
- start commit
- final commit
- files inspected
- files created
- files modified
- database changes
- simulation results
- frontend screens checked
- UI review notes
- command results
- known gaps
- next recommended task

UI review notes should cover:

- sidebar clarity
- page titles
- table density
- form usability
- empty states
- error states
- action button consistency

Keep `progress.md` short. Put detailed run evidence here.
